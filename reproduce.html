03 / Run It Yourself

Reproducibility

Clone the repo, install dependencies, and rebuild the pipeline, clustering, and write-up from scratch.

01

Clone the repository

Pulls in the processed datasets, scripts, notebooks, and both deliverables folders.

git clone https://github.com/S1mT/data510-OregonPedSafety.git
cd data510-OregonPedSafety
02

Install dependencies

Python 3.10+ recommended. All package versions are pinned in requirements.txt (pandas, numpy, scikit-learn, scipy, matplotlib, seaborn, geopandas, shapely, requests, folium).

python -m venv venv
source venv/bin/activate   # Windows: venv\Scripts\activate
pip install -r requirements.txt
03

Use the processed data, or rebuild it from raw

data/processed/FARSinfrastructure.csv and FARSmaster.csv are already included, so most of the analysis can run without re-pulling raw data. To rebuild from scratch: download the 2015–2024 national FARS CSV tables into data/raw/, then run the two-stage pipeline.

python data/scripts/initial.py   # builds FARSinfrastructure.csv
# set CENSUS_API_KEY in enrich.py before this step
python data/scripts/enrich.py    # builds FARSmaster.csv
04

Reproduce the clustering and figures

DBSCAN hotspot detection, hotspot profiling, and the interactive maps all read from data/processed/.

python data/scripts/DBSCAN.py
python data/scripts/hotspot_profiler.py
python data/scripts/interactive_map_generator.py
05

Rebuild the write-up

The final report is a Quarto document. Rendering regenerates the HTML and PDF with all figures and citations from refs.bib.

quarto render deliverables/M5-final-poster-and-writeup/final-writeup.qmd
